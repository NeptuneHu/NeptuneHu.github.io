# 本地演示说明

日期：2026-10-12

设计文档仍是第一版的目标：可部署网页、Supabase、高德、换设备还能打开。当天为了先试闭环，另外做了 `demo/`。下面只记录演示实际做成的样子，以及当天在设计范围之外加上的决定。

## 和设计文档不一样的地方

| 设计文档 | 本地演示 |
| --- | --- |
| Supabase 账号、数据库、文件 | 代码已接到 Supabase Auth、Postgres 和 Storage。需要自己的项目 URL 和 anon key，建表语句在 `demo/supabase/schema.sql` |
| 高德地理编码，服务端把 WGS-84 转成 GCJ-02 | 浏览器直接请求 BigDataCloud 逆地理和 Open-Meteo 城市搜索。地球仪用 WGS-84，不要再套 GCJ-02 |
| Leaflet 地图 | `react-globe.gl` 夜地球，贴图在 `demo/public/earth-night.jpg` |
| 换设备登录后数据还在 | 用同一个 Supabase 账号登录后，城市、照片和行程还在 |
| 城市名优先中文标准名 | 中国、香港、澳门、台湾保持中文。外国地点用英文或当地文字 |
| 行程生成不进第一版 | 当天另加了机票、火车票足迹。仍不生成行程，也不公开分享 |

## 当天定下的交互

- 点大洲会飞到该区域，列表按大洲筛选。七大洲都显示。
- 页面是浅鼠尾草绿底、奶油色卡片、毛玻璃按钮。标题是「去过的地方，会亮起来」。
- 字体栈是 Times New Roman，然后方正小标宋，然后宋体。这台电脑没装方正小标宋，中文会落到 Songti SC。装上「方正小标宋简体」后中文会自动用它。不要把商业字体文件放进仓库。
- 城市搜索按名称和国家去重，最多 5 条。选中出发地之后才出现到达地。
- 航线是连续弧线。点行程时，距离远的线会把镜头拉远，这样两端都在画面里。
- 航旅纵横没有给个人网站用的登录回调。演示只打开 https://www.umetrip.com/ 。导入方式是粘贴行程并勾选。不保存对方的密码、Cookie，也不调用他们的内部接口。
