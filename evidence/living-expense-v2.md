# PRD.md · 产品需求

最重要的一步。下面每条都能在 `v2/` 里对照验收。界面文案以 v2 为准。

## 产品

名字叫「生活费」。一笔钱从你按下「开始」的那一刻起，用 30 天均匀入账，每 0.1 秒刷新一次可支配余额。余额 = 已入账 − 已支出。

## 范围

做：设金额、看跳动、记支出、改金额、重置、自定义背景、看账单、把账单存成图或分享。

不做：见 `RESEARCH.md` 的「不做的事」。v1 的深色霓虹、口号和四格统计不再作为需求。

## 主路径

1. 第一次打开，输入这个月的生活费，或点 1200 / 1500 / 2000 / 2500 / 3000。
2. 点「开始」。周期从这一刻起算 30 天，支出清空。
3. 主屏显示可支配余额，精确到小数 6 位，每 0.1 秒更新。旁边是每秒入账、本周期进度、已入账、已支出。
4. 记一笔：金额必填，备注可选（最多 20 字），分类六选一，默认「外卖」。
5. 记下后余额立刻重算，新记录出现在列表最上面，可以删除。
6. 下次打开同一浏览器，直接回到主屏，余额按真实经过的时间补齐，不从 0 重新跳。

## 状态

| 状态 | 用户看到的 |
| --- | --- |
| 未开始 | 只有金额输入。「账单 / 调整 / 重置」不出现 |
| 入账中，余额 ≥ 0 | 胶囊写「入账」 |
| 入账中，余额 < 0 | 胶囊写「超支」，余额为负 |
| 满 30 天 | 入账停在整月金额，胶囊写「结束」，进度写「已结束」。支出仍可记 |
| 重置后 | 回到未开始。金额、周期、支出都清空。背景照片保留 |

## 规则

- 金额必须大于 0，且不超过 99,999,999，保存时四舍五入到分。空、0、负数、非数字，提示「请输入金额」，不进入下一步。
- 「调整」只改月金额。周期起点和支出记录不动，每秒入账和余额立即按新金额重算。
- 「重置」先确认「清空并重新开始？」。取消则什么都不发生。
- 删除一条支出后，累计支出和余额立即重算。
- 账单不下载。点「账单」进入页内账单：总支出、分类饼图、占比、明细。左上角「返回」回到跳动页。
- 饼图：鼠标或指针移到某一扇形或对应分类行，该块放大、其余变淡，同分类的明细一起亮。移开恢复。只有一个分类时是整圆。没有支出时是空心灰圆，文案「暂无支出」。
- 「保存 / 分享」：手机能调起系统分享时分享一张图；否则下载 PNG。图里有总支出、饼图、占比和明细。文件名形如 `生活费账单-20261012.png`。用户取消分享则不下载。
- 「背景」可选一张照片铺满页面，可更换、可移除。移除后回到淡色渐变。照片留在本机。

## 界面

- 字少。没有口号、长说明、页脚和重复统计。
- 系统字体，大圆角，主按钮用系统蓝。跟随系统浅色和深色。
- 顶栏和卡片是毛玻璃。有照片时玻璃更透，背后的照片能透出来。
- 按下按钮轻微缩小。记一笔时余额轻弹。新记录滑入。调整金额和背景从底部弹出。
- 系统打开「减少动态效果」或「减少透明度」时，动画停止，玻璃改为不透明底。

## 验收

用浏览器打开 `v2/index.html`，逐条看：

1. 不填金额点「开始」，停在设置页并提示。
2. 输入 2000 后开始，余额以小数后很多位往上走，约每秒增加 2000 / 86400 / 30 元。
3. 记一笔 12 元「午饭 / 外卖」，余额马上少 12，列表出现这条，空态消失。
4. 删掉这条，余额加回 12。
5. 把金额改成 3000，周期文案和已有记录还在，每秒入账变大。
6. 点账单，总额、饼图、明细一致；移到「外卖」时扇形和该行、该明细一起亮。
7. 保存或分享得到一张含总额和明细的图，页面本身不跳走。
8. 选一张照片再移除，页面回到淡色背景，刷新后与移除结果一致。
9. 重置并确认后回到设置页；再刷新仍是设置页。
10. 切到系统深色，页面变暗；打开减少动态效果，漂移和弹跳停止。
