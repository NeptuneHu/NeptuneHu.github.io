# 待办事项应用开发说明

## 项目概述

Focus Todo 是一个面向个人学习、工作和生活管理的响应式待办应用，支持任务增删改、完成状态切换、多条件筛选、模糊搜索、进度统计和本地持久化。

## 设计要素

- 深色界面，紫色与青色作为状态强调色
- 统计卡片展示全部任务、进行中数量和完成率
- 优先级、分类和完成状态采用清晰的视觉标签
- 桌面端与移动端均可正常使用

## 页面与内容结构

页面由顶部导航、任务概览、统计卡片、搜索筛选区、任务列表和新建编辑弹窗组成。

## 代码实现

项目使用 React、TypeScript、Vite 和 Tailwind CSS。Zustand 负责全局状态，LocalStorage 保存任务，date-fns 处理日期显示。

## 关键实现过程

任务包含 id、标题、描述、分类、优先级、截止日期、完成状态和创建时间八个字段。筛选条件可组合使用，搜索同时匹配标题与描述；新增、修改、删除和完成状态变化都会自动保存。

## 本地运行

在项目目录执行 `pnpm install` 和 `pnpm run dev`，浏览器访问本地地址。生产构建使用 `pnpm run build`，构建已验证通过。
